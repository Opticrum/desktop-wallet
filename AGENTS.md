## Learned User Preferences

- Prefer Vite + React + TypeScript for the static wallet mockup under `mockup/`.
- Keep framework scaffolding thin; spend effort on page UI/content because the mockup will change often.
- Brand the product as Opticrum Desktop; support Chinese/English UI with a language toggle.
- Use dual light/dark themes (slate gray + teal accents, default dark).
- No top bar — put logo in the left sidebar; theme and language toggles share one bottom row.
- Secondary detail pages replace the center panel only; keep left and right sidebars visible.

## Learned Workspace Facts

- `opticrum-wallet` is a Fiber desktop wallet + app marketplace front-end mockup (realistic predefined fake data).
- Main shell is left–center–right: left wallet/node/channel status (clickable into details), center app marketplace with a scrolling banner, right network overview / Fiber & LN news / changelogs.
